### [Demo](https://www.youtube.com/watch?v=g18fY-RX4cA)

## Usage

```sh
For testing, use a PHP development server with the root at public_html
All public pages will be through public_html/project
Get a free JSearch API Key: https://rapidapi.com/letscrape-6bRBa3QguO5/api/jsearch

In .env:
- DB_URL set to your database
- JSEARCH_API_KEY set to your API key
```
